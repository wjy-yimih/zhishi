# 知室 · 四门课的中文自学书桌

中文原创伴读网站，已开放概率论与数理统计、离散数学、数据结构与计算机系统。大学物理的电磁学保留待添加位置。

## 从哪里开始

双击本文件夹的 `index.html` 即可使用，无需安装依赖。整个文件夹可上传到 GitHub Pages，保持 `index.html` 与 `content` 文件夹在同一层。

概率统计建议先读 **概率入门**：先弄清“在谁里面数谁”，再区分事件、随机变量、分布、样本和参数。四个实验帮助理解条件概率、密度与累计、抽样均值、置信区间和双侧检验。

离散数学建议先读 **符号与证明**：从一句公式如何逐段读起，练习用例子、反例和证明区分“看起来对”与“为什么一定对”。词典可搜索数学符号和中文意思；课程内也附常用符号拆解。

C 和 C++ 还不熟悉时，建议先看左侧 **代码入门**。10 个入门主题依次解释变量、条件、循环、数组、函数、指针、结构体、动态内存、递归和教材类 C 写法。语法词典可以搜索 `*`、`&`、`->`、`i++` 等符号。

课程关键 C 示例支持点选任意一行查看中文解释、上/下一行阅读及展开全部解释。代码入门中有变量、循环、数组、指针的预设执行演示，可以观察变量表和输出变化。逐行阅读与执行顺序分别呈现，循环与递归可以返回前面的代码行。

代码点读面向站内示例；执行演示使用注明输入的预设状态，适合对照手算。函数片段会附类型、变量与合法输入说明。

## 四门课程

- **概率论与数理统计**：按盛骤、谢式千、潘承毅编、高等教育出版社第五版，保留15章65个小节，拆成104篇原创伴读并逐节链接。从基本事件与分布，到期望方差、极限定理、估计检验、方差分析与回归，再到bootstrap、R软件、随机过程、马尔可夫链、平稳过程及时间序列。讲清符号、条件、推导、反例，配逐步例题和自测。需要先修的内容在课内说明。R章6段示例支持逐行中文解释，需在R环境运行，网页不执行R。
- **离散数学**：按你提供的张清华主编、机械工业出版社《离散数学》目录，覆盖7章37个小节，拆为81篇原创伴读。依次为命题逻辑、谓词逻辑、集合、二元关系和函数、代数系统、典型代数系统、图论基础。正文从具体例子建立直觉，再逐字读符号、讲清条件、推导和反例。每课配至少4步例题、具体误区和自测，教材小节页面提供精确编号对照。定义约定和定理前提在相应正文中说明。
- **数据结构**：69篇核心伴读、26段逐行解释的C示例。按你提供的人民邮电出版社《数据结构（C语言版）》第2版（严蔚敏、李冬梅、吴伟民）的八章主题编排：绪论、线性表、栈和队列、串/数组/广义表、树和二叉树、图、查找、排序。相近知识点合并成原创伴读，部分平衡结构和综合算法作为补充。每课包含中文直觉、定义与条件、逐步例题、易错点和自测。
- **计算机系统**：保留《深入理解计算机系统》原书第3版的12章、55篇伴读和105个教材二级小节对照。

数据结构教材当前按章对照，具体小节编号以你手里的目录为准。本站讲解和代码为原创教学示例，建议结合教材原文及习题阅读。

## 动手实验

- 概率统计：条件概率与Bayes自然频数表、二项/正态分布与累计概率、样本均值和CLT模拟、已知方差正态均值的置信区间覆盖与双侧z检验。图形旁会说明数值近似、模拟对象与适用条件。
- 离散数学：可输入三个命题字母公式的真值表与等值比较、三元素关系的性质反例与闭包、有限模运算表与群条件、可编辑五点图的度数/连通/欧拉走法。真值表支持点开一行阅读逐层计算；闭包可撤销；欧拉走边可逐步前进与回退。
- 数据结构：闭区间二分查找、栈与循环队列、二叉树遍历、逐步排序。
- 计算机系统：8位补码、Cache地址拆分、简化虚拟地址翻译、Amdahl定律。

实验按主题支持参数调整、逐步操作或重置，并说明边界条件。无需后台或外部 API。

## 上传到 GitHub 并开启 Pages

1. 登录 GitHub，点右上角 **＋ → New repository**，或打开[新建仓库页面](https://github.com/new)。Repository name 填 `zhishi-study` 之类的名字，选择 **Public**；GitHub Free 可用公开仓库开启 Pages。可以将 **Add README** 开启，再点 **Create repository**，这样创建后会有文件列表。
2. 在仓库的 **Code** 页点 **Add file → Upload files**。打开桌面「知室」文件夹，选中里面的全部文件和子文件夹，拖到上传框。`content`、`icons` 和 `.nojekyll` 等一并保留。若创建的是空仓库，可先点首页的 **uploading an existing file** 链接。
3. 等文件上传完，填写一条提交说明，例如“上传知室网站”，选择提交到当前 `main` 分支，再点 **Commit changes**。上传列表里已有文件不等于已经提交。返回文件列表，确认直接看到 `index.html`、`app.js`、`content`、`icons`，外面没有再套一层「知室」。
4. 打开这个仓库的 **Settings → Pages**，在 **Build and deployment** 下将 **Source** 设为 **Deploy from a branch**。
5. 分支选择有这些文件的分支（通常为 `main`），目录选择 **/(root)**，点击 **Save**。
6. 等待发布完成，再回 **Settings → Pages** 复制它显示的网站地址。首次发布或更新可能需要数分钟，官方说明最长可能约10分钟。若失败，可在仓库 **Actions** 中查看 Pages 发布任务的状态。
7. 把这个网站地址发到手机，用 Safari 或 Chrome 打开。网站地址通常形如 `https://你的用户名.github.io/zhishi-study/`；`https://github.com/你的用户名/zhishi-study` 是源码仓库地址，不是学习网页。

页面资源、课程链接和主屏幕入口使用相对路径，支持上述带仓库名的项目子路径。保留文件之间的相对位置即可，无需把仓库改名为 `用户名.github.io`，也无需安装 Node、运行构建或购买域名。

如果仓库里已有旧版，可以上传这次文件夹中的完整内容并提交更新。新加的 `content/probability-*.js`、`content/probability.js`、`probability-tools.js`、`probability.css`、`mobile-study.js`、`site.webmanifest`、`icons`，以及更新的入口、应用和代码点读文件都应一起上传。建议每次上传整个文件夹里的内容，减少遗漏。

官方说明：[上传现有文件](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository) · [配置 GitHub Pages 发布源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。更细的首次操作和常见问题见 [手机访问说明.md](手机访问说明.md)。
